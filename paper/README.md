# Manuscript

Source and PDF for *Are Parameter-Efficient Fine-tuning Methods Really Different?*

The main document is `main.tex`. Figures, tables, bibliography and style files are included.

From the repository root, run `python3 scripts/build_paper.py`. This requires `latexmk` and pdfLaTeX on `PATH` and writes a compiled copy under `runs/paper-build/`. Use `--output` to choose another output root.
